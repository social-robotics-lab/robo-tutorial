# ファイルの説明
- robottools.py: RobotControllerにコマンドを送るクラス
- sample.py: ロボットの動作テストのサンプルプログラム
- sample.wav: sample.pyで再生する音声ファイル

# 注意
- sample.pyの中にロボットのIPアドレスをハードコーティングしている部分があるので、自身のロボットのIPアドレスに変更すること。

#VScodeの使い方
- VScodeでの初回実行前に、Pythonの拡張機能をインストールすること(これがないと実行できないし、実行ボタンもでない)
- VScodeの画面最左部に6つのメニュー項目(ファイルのアイコンや虫眼鏡やフラスコなど)がある。このうち5つめ(ブロック型)の[拡張機能(Extensiotns)]を選択し、現れた検索バーで、[Python]と検索する。おそらく上から2つめに表示される[Python]を選択し、青いボタン[enable]を押すことによって、拡張機能[Python]のインストールが完了する。
- 戻りたいときは、画面最左部のメニューのうち、1つめ(ファイルのアイコン)の[Explorer(エクスプローラー)]を押すといつもの画面に戻れます。
