# VScodeをはじめてつかうとき
### 言語設定 English → 日本語
- VScodeの画面左下の　設定ボタン(Manage)　を選択
- メニューバーの1つめの　コマンドパレット(Command Palet) を選択 (画面上部に検索バーが出現する)
- 検索バーに 'Configure Display Language' と入力し選択
- 日本語(設定したい言語) を選択　(再起動をする)

### 拡張機能 Python のインストール
#### VScodeでの初回実行前に、Pythonの拡張機能をインストールすること。(これがないと実行できないし、実行ボタンもでない)
- VScodeの画面最左部に、6つのメニュー項目(ファイルのアイコンや虫眼鏡やフラスコなど)がある
- このうち、5つめ(ブロック型)の [拡張機能(Extensiotns)] を選択する
- 検索バーで、 'Python' と検索し、検索結果から [Python] を選択する
- Pythonのアイコン横にある青いボタン [enable] を押すと、拡張機能[Python]のインストールが完了する

戻りたいときは、画面最左部のメニューのうち、1つめ(ファイルのアイコン)の [Explorer(エクスプローラー)] を押すといつもの画面に戻れます。

### フォルダの開き方
- 画面左上の [File(ファイル)] を選択
- [Open Folder(フォルダを選択)] を選択
- 開きたいフォルダ(workspaceなど)を選択し、開く

### プログラムの実行の仕方
- 実行方法1 ・・・ 画面右上の 実行ボタン を押す
- 実行方法2 ・・・ 画面下部のターミナルで、' python ファイル名.py ' と入力し Enter を押す

実行ボタンがないときやうまくいかないときは、拡張機能Pythonが入っていないからかもしれない。

# Githubからファイルをダウンロードする方法
### 方法1 ファイル自体をダウンロードし、workspaceに移動
-	GitHubで sample.py(ダウンロードしたいファイル) を表示する
-	右上の Download raw file ボタンをクリック(PCの[ダウンロード]にフォルダがダウンロードされる)
-	PCのエクスプローラーやFinderを開き、該当のファイルを選択する
-	ドラッグ&ドロップをして、workspaceまで移動。(エクスプローラーやFinderの中のworkspaceでもいいし、VScodeの中のworkspaceでもいい)

ドラッグ&ドロップのコツ: おそらくドラッグ&ドロップに手詰まると思う。スマートにファイルを移動させる裏技(アドレスバーやホバー)はあるが、ふつうは、画面を2つ開いて、一方から一方までドラッグ&ドロップするのが無難。

### 方法2 workspaceの中に白紙のsample.pyを作り、その中身をgithubからコピぺして埋める方法。
- VScodeの workspace を開いた状態で、フォルダ名の横に表示される「新しいファイル」ボタンを押して sample.py を作成
-	GitHubで sample.py(ダウンロードしたいファイル) を表示する
-	右上の Copy raw file ボタンをクリック(クリップボードに'プログラムの中身'がコピーされる)
-	VScodeに戻り、sample.pyを開く
-	画面中央(sample.pyの編集画面)をクリックして、先ほどコピーした内容をペーストする


# 注意
- sample.pyの中にロボットのIPアドレスをハードコーティングしている部分があるので、自身のロボットのIPアドレスに変更すること。
