# VisualStudioCode(VSCode)をはじめてつかうときに
## 言語設定 English → 日本語
(表示言語を変更したい人は以下の手順で設定)
- VSCodeの画面左下の　設定ボタン(Manage)　を選択
- メニューバーの1つめの　コマンドパレット(Command Palet) を選択 (画面上部に検索バーが出現する)
- 検索バーに 'Configure Display Language' と入力し選択
- 日本語(設定したい言語) を選択

変更後、再起動されます

## 拡張機能 Python のインストール
#### VSCodeでの初回実行前に、Pythonの拡張機能をインストールすること。(これがないと実行できないし、実行ボタンもでない)
- VSCodeの画面最左部に、6つのメニュー項目(ファイルのアイコンや虫眼鏡やフラスコなど)がある
- このうち、5つめ(ブロック型)の [拡張機能(Extensiotns)] を選択する
- 検索バーで、 'Python' と検索し、検索結果から [Python] を選択する
- Pythonのアイコン横にある青いボタン [enable] を押すと、拡張機能[Python]のインストールが完了する

戻りたいときは、画面最左部のメニューのうち、1つめ(ファイルのアイコン)の [Explorer(エクスプローラー)] を押すといつもの画面に戻れます。

## フォルダの開き方
- 画面左上の [File(ファイル)] を選択
- [Open Folder(フォルダを選択)] を選択
- 開きたいフォルダ(workspaceなど)を選択し、開く

## プログラムの実行の仕方
- 実行方法1 ・・・ 画面右上の 実行ボタン を押す
- 実行方法2 ・・・ 画面下部のターミナルで、' python ファイル名.py ' と入力し Enter を押す

実行ボタンがないときやうまくいかないときは、拡張機能Pythonが入っていないからかもしれない。
